# BERZINE

**BERZINE** is a minimalist, web-based zine maker designed for short texts, poetry, reflections, and visual expression.  
Built with a DIY spirit — quick, quiet, and expressive.

> *Yang pendek kadang lebih bermakna.*

---

## ✦ What is BERZINE?

BERZINE allows users to create a one-page digital zine by combining:
- Short text (up to 100 characters)
- A title and author tag
- Optional photo
- Visual templates and accent colors

The final result can be exported as a **1080 × 1920 PNG**, ready for Instagram Stories or digital sharing.

No account.  
No backend.  
No distractions.

---

## ✦ Features

- Short-text focused (max 100 characters)
- Multiple visual templates (Riot, Soft, Ink, Dusk, Torn)
- Custom accent colors per template
- Optional photo upload (client-side only)
- Instagram Story–ready export (PNG 1080×1920)
- Runs entirely in the browser (HTML + CSS + JS)

---

## ✦ Tech Stack

- HTML5
- CSS3 (inline styling)
- Vanilla JavaScript
- `html2canvas` for export rendering
- Google Fonts

No framework.  
No database.  
No server.

---

## ✦ How to Use

1. Open the website
2. Write a title and short text
3. (Optional) Add a photo
4. Choose a template and accent color
5. Click **“Simpan sebagai PNG”**
6. Share your zine

---

## ✦ Philosophy

BERZINE is built on the idea that:
- Text doesn’t need to be long to be meaningful
- Design should support words, not overpower them
- Creation should feel light, fast, and personal

This project is part of an exploration of **digital poetry, micro-publishing, and contemporary DIY culture**.
